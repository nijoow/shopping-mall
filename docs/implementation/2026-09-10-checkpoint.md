## 제작 중 발견해 수정한 문제

- Blender의 원본 재질 변형 메타데이터가 새 부위 재질을 덮어쓰던 문제를 제거했어.
- 직접 제작한 로우탑의 열린 끝과 떠 있는 패널/레이스를 수정하고 재질 좌표를 추가했어. 최종 조형 검수는 아직 남아 있어.
- Next 개발 서버의 URL 정규화와 실제 Host/Origin 차이를 고려해 동일 출처 검사를 수정했어.
- 개발 중 코드 갱신 때 옛 클래스가 남아 오류 분류를 깨뜨리지 않도록 DB 연결만 공유하고 저장소 구현은 다시 구성하게 했어.
- 모바일에서 색상 버튼을 하단 주문 영역이 가리던 문제를 해결했어. 뷰어와 구매 영역은 고정된 그리드 안에 두고 편집 패널만 스크롤해.
- 주문 승인 뒤 응답이 끊기면 같은 요청 키의 기존 주문을 조회해 복구하도록 했어.

## 다음에 필요한 작업

1. **모델 품질:** 러너의 목표 실루엣과 로우탑의 조형/봉제/각인/표면을 더 다듬어야 해. 현재 자산은 초기 검수용이고 선택한 콘셉트 이미지와 같은 품질이 입증된 상태가 아니야.
2. **부품 형태 교체:** 아직 제공하지 않아. 현재 4개 부위의 색과 어퍼 재질·각인을 연결했으며, 형태 교체는 합의한 품질 기준으로 별도 검증해야 해.
3. **소셜 실인증:** 제공자별 실제 인증 성공·동의 취소·콜백 설정·기존 계정 전환을 확인해야 해. 저장소의 이관 로직 테스트와 실제 OAuth 성공은 구분해.
4. **공개 저장소:** 현재는 개발용 SQLite야. 공개 배포 환경에 맞는 지속 저장소, 만료 데이터 정리, 요청 제한, 보관 정책을 완성해야 해. 기존 원격 DB는 건드리지 않았어.
5. **상세 UX:** 가격/색상 등 탐색 필터 확장, 긴 콘텐츠/손상된 로컬 초안/저장 충돌의 복구를 더 다듬어야 해.
6. **실기기:** 데스크톱 브라우저와 모바일 에뮬레이션 결과만 있어. 실제 모바일 FPS·발열·키보드·스크린리더 검수는 남아 있어.

문의·후기·별도 운영 화면은 사용자 결정대로 후순위야. 실제 결제 미연동은 합의한 데모 제품 범위이므로 결함으로 취급하지 않아.
