# 3D 품질·성능 개선 기록 — 2026-10-03

이 기록은 새 러너 v2·로우탑 v3 후보와 렌더러의 로컬 검증 증거다. 운영 배포·실기기 품질 승인과 구분한다. 저장·공유·주문 연결의 최종 검증은 통합 작업에서 수행한다.

## 변경

- 러너: Shopify CC BY 4.0 조형·UV·표면을 유지하고 편집 재질별로 메시를 병합했다. 1024px를 넘는 텍스처를 축소했다. 원래 밑창을 raycast한 위치에 얕은 고무 접지 부품을 맞췄다. 새 부품에 원본 UV atlas를 재사용했을 때 드러난 왜곡은 별도의 무광 `sole.grip` 재질로 수정했다. [원본 및 출처](../../public/models/source/shopify-source.md)를 유지했고 새 GLB의 copyright에도 표시했다.
- 로우탑: 연속 칼라·안감·어퍼·패널의 기존 last를 유지하면서 곡선 해상도와 단면 분할을 줄였다. 닫힌 cupsole에 얕은 herringbone 접지 부품을 추가했다. 새 v3의 측면 패널도 선택한 표면 재질을 적용해 어퍼와 질감을 맞춘다. 이전 v1/v2의 패널 동작은 유지한다.
- 표면: 사용자 색을 과도하게 어둡게 만드는 albedo를 줄이고 roughness texture를 추가했다. 메시 반복 주기를 낮춰 작은 화면에서도 짜임을 구분할 수 있게 했다. normal 강도를 표면별로 조절했다.
- 각인: 실측 raycast 지점의 법선 방향을 따라 decal을 배치한다. 8자의 폭을 확보했고 밝은/어두운 바탕에 대비되는 색을 사용한다. low v2/v3의 각인은 측면 패널에 놓인다.
- 뷰어: 모델/버전 변경 시 포스터·loading 상태와 캡처 준비 상태를 초기화한다. 모델 요청 실패·WebGL context 유실 시 캡처를 무효화하고 cache를 지운 뒤 재시도한다. 폐기된 캡처 함수도 오류를 반환한다. 실제 렌더 이후에만 캡처를 전달하고 PNG에 캔버스 배경을 채운다. 공유 GPU geometry·원본 texture는 캐시에 유지하고 뷰어가 만든 재질·표면·decal만 정리한다. 로우탑의 접지 그림자 높이를 실제 sole 높이에 맞췄다.
- 제작 스크립트: 고정 v1/v2 출력을 제거했다. 모델·포스터의 명시적 새 경로가 필요하며 기존 파일이 있으면 생성 전에 거절한다. 도우미를 import할 때 에셋이 생성되지 않는다.

## 버전과 구조 측정

GLB JSON의 meshes/primitives 및 indexed accessor count로 측정했다. primitive 수는 에셋 본체의 재질 draw 수다. ContactShadows·각인·조명의 전체 renderer draw 수를 의미하지 않는다.

| 모델      |   파일 크기 | 메시/primitive |    정점 |  삼각형 |
| --------- | ----------: | -------------: | ------: | ------: |
| runner v1 | 6,447,352 B |        83 / 83 |  13,540 |  22,700 |
| runner v2 | 4,274,692 B |          5 / 5 |  15,412 |  25,508 |
| low v2    | 7,158,940 B |          7 / 7 | 155,148 | 271,848 |
| low v3    | 2,566,240 B |          7 / 7 |  57,038 |  90,992 |

러너 용량은 33.7%, 본체 primitive는 94.0% 줄었다. 접지 geometry 추가로 삼각형은 12.4% 늘었다. 로우탑 용량은 64.2%, 삼각형은 66.5% 줄었다. 별도 decoder나 원격 texture CDN을 추가하지 않았다.

기존 파일의 SHA256을 작업 전·후 비교해 보존을 확인했다.


## 실제 렌더·복구 검증

Blender 5.1.0/Cycles 32 samples로 새 GLB와 동일 geometry의 포스터를 생성했다. renderer 검증에는 저장소의 실제 `ShoeCanvas`, `ProductViewer`를 esbuild로 묶은 전용 fixture와 로컬 서버를 사용했다. `agent-browser` CLI가 없어 번들 Playwright와 설치된 Google Chrome headless를 사용했다. 기존 앱 서버와 DB는 사용하지 않았다.

- 두 새 모델의 front/side/heel/sole 8개 화면을 확인했다. 새 접지 부품이 실제 밑창에 붙어 있고 칼라·혀·끈·패널·앞코가 화면 안에 들어오는지 점검했다.
- 모델별 mesh/leather/suede × 밝은/어두운 색 × 각인 0/8자(`NIJOOW08`)의 24개 측면 화면과 512×384 PNG를 생성했다. 8자 각인은 밝고 어두운 바탕에서 식별되고 빈 각인은 남지 않는다. 정상 matrix에 pageerror가 없었다.
- GLB 요청을 강제로 실패시킨 실제 ProductViewer에서 fallback·캡처 `null`·재시도 후 유효 PNG를 확인했다.
- `WEBGL_lose_context`로 context를 유실시키고 fallback·캡처 `null`·기존 캡처 함수 오류·재시도 후 유효 PNG를 확인했다. 이 2개 오류는 유도한 실패와 일치한다.

증거는 Git 제외 `artifacts/2026-10-03-3d-quality/`에 있다. `{runner,low}-contact-sheet.png`는 4시점과 재질·색·각인 화면을 묶었다. `*-capture.png`는 실제 다운로드 함수의 결과다. `asset-measurements.json`, `browser-measurements.json`, `rotation-measurements.json`, `recovery.json`은 원시 수치와 동작 결과다.

## 같은 조건의 성능 측정

로컬 macOS·Google Chrome headless, viewport 900×640, DPR 1, localhost·비제한 네트워크, 브라우저 cache disabled. GLB마다 새 browser context, 앱 코드 실행 시작→첫 렌더 뒤 캡처 전달, PNG 캡처 20회 평균을 측정했다. 각 모델의 60 pointermove 회전 중 RAF 간격도 기록했다. 이 값은 GPU profiler나 저사양 실기기 측정이 아니다.

| 모델      | 준비까지 단일 샘플 | GLB fetch 단일 샘플 | PNG 캡처 20회 평균 | 회전 RAF p95 |
| --------- | -----------------: | ------------------: | -----------------: | -----------: |
| runner v1 |           526.7 ms |             15.4 ms |            3.81 ms |      16.8 ms |
| runner v2 |           446.7 ms |              8.2 ms |            3.53 ms |      16.8 ms |
| low v2    |           440.8 ms |             11.3 ms |            3.29 ms |      16.7 ms |
| low v3    |           433.1 ms |              7.0 ms |            3.36 ms |      16.8 ms |

4개 회전 샘플에서 33ms를 넘는 RAF 간격은 없었다. 로우탑의 준비/캡처 차이는 작고 측정 편차 범위일 수 있다. 용량·geometry 감소를 실제 모든 기기의 로딩·FPS 향상으로 일반화하지 않는다. 이 fixture에는 앱 초기 hydration·DB·네트워크 변동이 포함되지 않는다.

## 재생성

이미 보존된 파일에 이 명령을 실행하면 거절된다. 다음 버전 후보의 **새 경로**로 바꿔서 실행한다. Blender의 Python 오류를 명령 실패로 처리하도록 `--python-exit-code 1`을 사용한다.

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup \
  --python-exit-code 1 --python scripts/build-runner-quality.py -- \
  --source public/models/runner-v1.glb \
  --model-output public/models/runner-vNEXT.glb \
  --poster-prefix public/editorial/runner-vNEXT

/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup \
  --python-exit-code 1 --python scripts/build-low-v2.py -- \
  --model-output public/models/low-vNEXT.glb \
  --poster-prefix public/editorial/low-vNEXT --quality-v3
```

## 남은 범위

시각 자료를 확인한 로컬 후보이며 사용자의 최종 시점별 승인과 기준 기기의 실제 조작 검수를 대신하지 않는다. 절차적으로 만든 로우탑의 기본 last·칼라 높이는 유지했다. 미세 grain 차이는 축소 화면에서 제한적이며 물리적 소재 품질을 보증하지 않는다. 다운로드 PNG·실제 앱 컨테이너의 반응형, 저장→재열기→공유→주문 일치, 이전 모델 버전 호환은 통합 단계에서 확인해야 한다. iOS/Android 실기기·저사양 GPU·느린 네트워크는 이번 fixture로 검증하지 않았다.
