브랜드 기본 이름은 NIJOOW, 스니커즈 라인업은 러너 1종과 로우탑 1종으로 확정했어. 아래 제품 형태·문구·세부 레이아웃은 콘셉트 예시이고 실제 3D 모델, 최종 UI, 제작 가능한 품질의 검증 결과는 아니야. 무료 에셋과 직접 제작 계획은 그대로 유지해.

## 01. 패션 매거진형

**채택된 기본 방향이야.** 큰 타이포, 비대칭 사진, 겹치는 제품 이미지로 편집숍의 개성을 강조해. 홈·컬렉션뿐 아니라 상품 상세와 커스텀 스튜디오도 같은 시각 스타일로 구체화해. 실제 구현에서는 모바일의 읽는 순서와 제품 클릭 영역을 따로 설계해야 해.

## 02. 전시 갤러리형

제품을 전시물처럼 크게 보여주고 공간과 빛으로 분위기를 만들어. 대표 상품의 형태와 재질을 강조하기 좋아. 제품 목록 탐색으로 자연스럽게 이어지는 동선이 중요해.

## 03. 미래적인 랩

확대된 제품과 부위 표시, 색·재질 도구를 전면에 둬서 3D 개인화 기능을 바로 보여줘. 커스텀 스튜디오 화면의 출발점으로도 적합해. 의류·잡화가 있는 편집숍이라는 성격도 함께 전달해야 해.
