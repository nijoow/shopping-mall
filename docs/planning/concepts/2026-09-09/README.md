## 01. 패션 매거진형

**채택된 기본 방향입니다.** 큰 타이포, 비대칭 사진, 겹치는 제품 이미지로 편집숍의 개성을 강조합니다. 홈·컬렉션뿐 아니라 상품 상세와 커스텀 스튜디오도 같은 시각 스타일로 구체화합니다. 실제 구현에서는 모바일의 읽는 순서와 제품 클릭 영역을 별도로 설계해야 합니다.

## 02. 전시 갤러리형

제품을 전시물처럼 크게 보여주고 공간과 빛으로 분위기를 구성합니다. 대표 상품의 형태와 재질을 강조하는 데 적합합니다. 제품 목록 탐색으로 자연스럽게 이어지는 동선이 중요합니다.

## 03. 미래적인 랩

확대된 제품과 부위 표시, 색·재질 도구를 전면에 배치하여 3D 개인화 기능을 보여줍니다. 커스텀 스튜디오 화면의 출발점으로도 적합합니다. 의류·잡화를 포함한 편집숍이라는 성격도 함께 전달해야 합니다.
