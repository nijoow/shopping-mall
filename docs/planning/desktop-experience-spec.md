# NIJOOW 데스크톱 화면 상세 명세

2026-09-09 · 추천안으로 진행하는 1차 상세 기획 · 2026-09-10 첫 구현 상태는 별도 체크포인트 참고

[제품 기획서](/Users/woojin/Desktop/works/shopping-mall/docs/planning/3d-commerce-portfolio.md)의 확정 범위를 실제 화면으로 옮기는 명세야. 사용자 선택은 패션 매거진형, NIJOOW 이름, 러너/로우탑 각 1종, 스니커즈 3D 기본, 전용 전체 화면 편집, 현실적인 제품 표현, 데스크톱 우선이야.

문의·후기·별도 운영 화면은 초기 화면에서 제외해. 가격·문구·모델의 세부 형상과 아래 치수/색상은 구현과 검수를 위한 초기 설계값이고, 이미 완성된 결과나 이미지에서 정밀 추출한 수치가 아니야.

## 2. 홈 — 패션 매거진의 표지와 목차

### 배치

- 64px 헤더: NIJOOW, 쇼핑·스니커즈·의류·잡화·내 디자인, 검색·찜·장바구니·내 공간.
- 첫 편집 영역: 12열 기준, 왼쪽 약 4열은 큰 제목과 CTA, 중간 약 5열은 러너 전체 컷, 오른쪽 약 3열은 로우탑과 의류 디테일을 배치해.
- 러너 컷은 배경 사진의 경계를 일부 넘어가되 제품 제목과 버튼의 조작 영역을 가리지 않아.
- 제목은 시안의 SNEAKER EDIT 같은 짧은 컬렉션 제목을 사용해. 최종 카피는 제품 콘셉트와 맞춰 정리해.
- 다음 영역은 의류·가방·제품 디테일을 다른 크기의 이미지로 구성한 편집 섹션, 이어서 비교하기 쉬운 추천 상품 목록을 보여줘.

### 행동

- `커스텀 시작`: 홈의 대표 모델과 프리셋이 선택된 스튜디오로 이동해.
- `상품 보기`: 같은 모델/프리셋의 상품 상세로 이동해.
- 사진 영역 전체가 링크라면 초점 표시와 명확한 접근성 이름을 제공해. 링크 안에 별도의 버튼을 중첩하지 않아.
- 상품 카드마다 제목·가격·3D/커스텀 지원 여부를 보여줘. 일반 의류·잡화에는 지원하지 않는 3D 기능을 표시하지 않아.

홈은 렌더된 정지 이미지로 빠르게 보여줘. 모든 사진마다 별도 WebGL 캔버스를 띄우지 않아. 상세와 스튜디오가 본격적인 3D 조작을 담당해.

## 3. 상품 상세 — 3D를 보면서 구매를 판단

### 데스크톱 배치

| 영역 | 배치 | 내용 |
|---|---|---|
| 상단 경로 | 헤더 아래 | 쇼핑 / 스니커즈 / 제품. 뒤로 이동하면 목록 필터·스크롤 복원 |
| 제품 무대 | 왼쪽 약 7열, 최소 높이 560px 기준 | 스니커즈는 3D 기본. 초기 프레임은 같은 구성의 대표 이미지 |
| 정보 패널 | 오른쪽 약 5열, 내용 폭 360~440px 기준 | 제품명·가격·짧은 설명·추천 컬러웨이·사이즈·주요 행동 |
| 미디어 도구 | 제품 무대 하단 | 전체·측면·후면·밑창, 사진 보기, 시점 초기화 |
| 상세 콘텐츠 | 첫 영역 아래 | 소재/구조 컷, 사이즈 가이드, 가상 배송·취소 안내, FAQ |

정보 패널은 헤더 아래에 sticky로 두되 내용이 화면보다 길면 끝까지 접근 가능해야 해. 휠 이벤트를 가로채서 페이지를 못 내리게 하지 않아. 확대·축소는 명시적인 버튼과 뷰어가 활성화된 상황의 조작으로 제공해.

### 기본 3D 상태

1. 상품명·가격·옵션과 대표 이미지를 먼저 표시해.
2. 모델을 자동 로드하고 같은 카메라/구성으로 대표 이미지를 대체해. 로딩 때문에 무대 크기가 바뀌면 안 돼.
3. 드래그 회전, 확대/축소, 대표 시점 버튼을 제공해. 자동 회전은 기본으로 끄고 조작 힌트를 한 번 보여줘.
4. 모델을 못 읽으면 사진을 유지하고 `3D를 불러오지 못했어`와 재시도를 제공해. 사진과 일반 상품 구매는 계속 사용할 수 있어.
5. WebGL 미지원에서는 사진/준비된 프리셋 구매를 제공하고 자유 편집 제한을 안내해.

### 주요 행동

- `내 디자인으로 만들기`: 현재 모델·컬러웨이·사이즈를 전용 스튜디오에 전달해. 편집 진입 자체는 사이즈 미선택이어도 가능해.
- `장바구니 담기`: 현재 판매 프리셋과 필수 구매 옵션을 검사해 담아. 결과를 화면에 알리고 계속 볼 수 있게 해.
- `바로 주문하기`: 현재 구성만 체크아웃으로 전달해. 기존 장바구니의 다른 줄은 유지해.
- 필수 사이즈가 없으면 사이즈 영역에 이유를 표시하고 초점을 이동해. 품절은 안내와 함께 구매 행동을 제한해.
- 일반 2D 상품은 같은 정보 패널과 구매 규칙을 사용하고, 제품 무대에는 사진 갤러리를 표시해.

## 4. 전용 전체 화면 스튜디오 — 제품 제작 작업 공간

사이트 내 전용 경로가 뷰포트를 채우는 방식으로 해. 브라우저 전체 화면 API 권한을 요청하지 않아. 주소로 다시 열 수 있고 일반 뒤로 가기도 동작해.

### 배치

| 영역 | 배치 | 내용 |
|---|---|---|
| 스튜디오 상단 바 | 높이 64px | NIJOOW, 상품으로 돌아가기, 디자인 이름, 저장 상태, 실행 취소/다시 실행 |
| 제품 캔버스 | 남은 폭, 오른쪽 도구 제외 | 중립 조명의 큰 제품 뷰, 선택 부위 강조, 시점 도구 |
| 편집 패널 | 오른쪽 360px 기준 | 프리셋, 부위/색, 재질, 각인. 형태 구성은 품질 검증 통과 때만 추가 |
| 구매 검토 영역 | 편집 패널 아래쪽 | 기본가·추가 옵션·합계, 사이즈, 주문 전 검토 |
| 최종 검토 | 패널의 마지막 단계 | 구성 요약·썸네일·사이즈·가격, 장바구니 담기/바로 주문 |

한 화면에서 캔버스와 도구가 함께 보여야 해. 패널이 길어지면 패널 내부를 스크롤하고 캔버스는 유지해. 공통 모바일 내비와 일반 페이지 푸터는 스튜디오에 노출하지 않아.

### 편집 규칙

- 부위는 제품 직접 클릭과 텍스트 목록 모두로 선택해. 선택 부위는 색을 바꿔도 원래 제품 색을 오해하지 않도록 얇은 강조선/짧은 강조 효과로 표시해.
- 색 이름과 값, 재질 이름·샘플을 함께 보여줘. 허용하지 않은 부위/재질 조합은 선택지에 나오지 않아.
- 각인은 선택한 모델의 지원 위치와 문자 규칙을 따라. 잘못된 문자는 입력 근처에 안내하고 이미 작성한 나머지 내용은 유지해.
- 부품 교체를 채택하면 새 부품에서 사용할 수 없는 재질·각인 선택을 사전에 알려줘. 대체 값을 조용히 적용하지 않아.
- 실행 취소/다시 실행은 디자인 편집만 대상으로 하고 카메라 이동은 포함하지 않아.
- 원본 비교는 현재 초안을 보존한 채 잠시 원본을 보여줘.
- 디자인을 바꾸면 옵션 가격과 합계가 함께 갱신돼. 주문 전에는 서버 견적으로 다시 검증해.

### 저장과 이동

| 상태 | 표시 / 행동 |
|---|---|
| 변경 없음 | `저장됨`과 최근 저장 시각 |
| 변경 후 대기 | `저장 중` 표시, 최신 변경을 묶어 저장 |
| 저장 성공 | 저장된 버전과 썸네일이 일치하도록 연결 |
| 저장 실패 | 현재 초안을 유지하고 `저장하지 못했어 · 다시 시도` 제공 |
| 미저장 변경이 있는 상태에서 나가기 | 로컬 복구 초안을 남기고 필요한 경우 나가기 확인. 저장된 정상 상태에서는 매번 확인하지 않아 |
| 모델을 바꾸기 | 원래 모델의 초안을 보존해. 새 모델에 호환되지 않는 설정을 그대로 복사하지 않아 |
| 상세로 돌아가기 | 출발 상품·사이즈와 연결된 초안 유지. 계속 편집할 수 있어 |
| 로그인/콜백 왕복 | 동일 디자인/단계로 복귀하고 기존 계정 자료와 함께 안전하게 보관 |

## 5. 화면 간 전달 계약

| 이동 | 반드시 전달/보존할 값 |
|---|---|
| 홈 → 상세/스튜디오 | 제품 ID, 모델 ID/버전, 추천 프리셋 |
| 상세 → 스튜디오 | 현재 제품 구성, 선택한 사이즈, 돌아올 경로 |
| 스튜디오 → 장바구니 | 확정 디자인 버전, 모델/부품 버전, 사이즈, 수량 |
| 장바구니 → 편집 | 수정할 장바구니 줄과 디자인 사본. 완료 시 해당 줄만 교체 |
| 스튜디오 → 바로 주문 | 현재 디자인/사이즈만 주문 대상으로 전달 |
| 모의 주문 → 주문 상세 | 가격·구성·디자인 스냅샷과 소유자. 현재 카탈로그 변경에 따라 변하지 않아 |
| 익명 → 소셜 로그인 | 디자인·찜·장바구니·데모 주문 전체. 재시도해도 중복되지 않아 |

클라이언트의 가격·소유자 ID·임의 옵션은 서버 권한/검증의 근거로 삼지 않아. 이미지는 디자인 데이터를 표현하는 산출물이야. 사진만 같고 구성 데이터가 다른 상태는 완료로 보지 않아.

## 6. 반응형과 접근성

- 1200px 이상: 데스크톱 기본 구성. 스튜디오 패널 360px, 캔버스에 나머지 공간 배분.
- 768~1199px: 여백과 편집 패널을 조정하고 상품 상세는 사용 가능한 폭에 따라 2열/1열로 전환해. 내용이 넘치는 고정 폭을 강제하지 않아.
- 767px 이하: 상세는 제품→정보→행동 순서. 스튜디오는 상단 제품 뷰와 하단 패널을 함께 유지해.
- 모바일 키보드가 열리면 각인 입력과 적용/닫기 조작을 우선 보여주고, 닫으면 편집기 높이와 시점을 복원해.
- 시각적으로 숨긴 단계는 탭 순서에서도 제외해. 부위·팔레트·재질·사이즈는 키보드 선택과 선택 상태의 낭독을 제공해.
- 모달에는 이름, 초기 포커스, 포커스 가두기/복원, ESC를 제공해. 각 필터 인스턴스의 ID는 고유해야 해.
- 제품의 모든 편집은 캔버스를 클릭하지 않고도 완료 가능해야 해. 3D 캔버스 옆에 제품명과 구성 요약을 제공해.
- 중요한 가격·구매 버튼·저장 오류에는 텍스트 대비를 검수하고, 터치 대상은 기본 44px 이상의 조작 영역을 확보해.

## 7. 모션 초기값

모션은 상태 변화와 조작 결과를 이해하는 데 사용해. 아래 값은 구현 초기값이며 실제 조작감을 확인하면서 조정해.

| 동작 | 초기값 |
|---|---|
| 버튼/선택 표시 | 120~180ms |
| 패널·이미지 전환 | 180~240ms |
| 대표 카메라 시점 이동 | 350~500ms, 사용자가 드래그하면 중단 |
| 감소된 모션 | 불필요한 이동/회전 제거, 즉시 변경 또는 짧은 페이드 |

모델을 회전/편집하지 않는 동안에는 상시 애니메이션을 돌리지 않아. 백그라운드 탭·화면 밖의 뷰어도 렌더링을 쉬도록 해.

## 8. 모델 시제품의 첫 실행 묶음

1. **러너 후보/원형 확보:** 무료 자산 중 수정과 웹 공개 범위를 확인할 수 있는 후보를 검수하고, 적합한 원형이 없으면 직접 제작한 기본 형상을 비교해.
2. **현실적인 표면 제작:** 메시·가죽·고무의 질감, 패널 경계, 끈 두께, 밑창 디테일을 정리해. 단색 매끈한 외형만으로 제품 품질 검수를 통과시키지 않아.
3. **편집 가능성 검증:** 부위별 색·재질·각인이 제대로 적용되는지 대표 각도에서 확인해.
4. **부품 교체 시험:** 소수의 교체 부위와 변형을 만들어 모든 노출 조합의 형태·접합·표면을 검수해. 기준 미달이면 합의한 색·재질·각인안으로 진행해.
5. **화면 연결 확인:** 원형을 상세의 기본 뷰어와 전용 스튜디오에 같은 데이터로 표시해. 초기 로딩·실패 대체·편집 성능을 기록해.
6. **로우탑 제작:** 확정된 자산 규칙과 검수 절차를 적용해 두 번째 실루엣을 완성해. 러너와 같은 모델에 색만 바꿔 다른 모델로 표시하지 않아.

산출물은 모델/재질 원본, 내보낸 웹 자산, 부위/옵션 정의, 대표 각도 캡처, 성능 측정 조건, 부품 교체 채택 근거야. 실제 실행 전이므로 모델 품질과 성능을 이미 확인한 것으로 표현하지 않아.

## 9. 화면 개발의 완료 판정

- 선택한 매거진형 시안의 타이포·제품 중심 구성·비대칭 이미지가 유지돼.
- 상세에 들어가 별도 3D 활성화 클릭 없이 모델을 조작할 수 있어.
- 로딩/실패에도 같은 상품의 이미지·정보·구매 경로가 남아.
- 전체 화면 스튜디오에서 제품과 도구를 동시에 보고 조작할 수 있어.
- 상세→편집→장바구니→주문에서 동일한 디자인 버전이 이어져.
- 로그인, 뒤로 가기, 새로고침, 저장 실패에도 작업과 기존 데이터가 보존돼.
- 데스크톱 검수를 우선하고 모바일 구매/편집도 실기기에서 별도 검증해.
