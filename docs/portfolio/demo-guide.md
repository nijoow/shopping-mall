# NIJOOW 포트폴리오 시연 가이드

기준: 2026-10-03 로컬 구현. 운영 사이트에 같은 변경이 배포되었는지는 별도로 확인해. 시연은 개인 데이터가 없는 새 브라우저 프로필이나 시크릿 창에서 게스트로 시작해.

## 전달할 가치

스니커즈를 고르는 화면에서 직접 편집한 디자인의 저장·공유·모의 주문까지 연결되는 편집숍이야. 매거진형 탐색 화면과 3D 편집을 함께 보여주고, 주문 후에도 주문 당시 디자인을 보존하는 흐름으로 마무리해. 의류·잡화는 이미지 기반 상품이고, 3D 편집은 러너와 로우탑에 제공해.

소개 한 문장: “스니커즈의 색상·재질·각인을 3D로 편집하고, 같은 디자인으로 저장·공유·주문까지 체험할 수 있는 가상 편집숍입니다.”

## 60–90초 시연

아래는 75초를 기준으로 잡은 진행안이야. 로딩 시간은 실행 환경에 따라 달라지므로 성능 수치로 제시하지 마. 짧게 진행할 때 공유 탭 확인을 생략하고, 90초까지 사용할 때 마지막 배송 체험을 추가해.

| 구간          | 화면과 행동                                                                                                                         | 보여줄 결과                                                                  |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 0–15초        | `/shop/sneakers` → **EVERYDAY LOW** 상세. 3D가 로드된 뒤 측면·후면을 확인하고 **내 디자인으로 만들기** 선택                         | 상품 탐색에서 편집으로 자연스럽게 이동                                       |
| 15–40초       | `/studio/low`. 패널 색상, 어퍼 재질, 영문 각인 `NIJOOW` 변경. **저장 완료** 확인                                                    | 부위 선택·표면·각인이 실제 3D에 반영되고 저장됨                              |
| 40–55초       | **내 디자인** → 저장한 디자인 재열기. **공유**로 생성한 링크를 새 탭에서 열어 확인                                                  | 같은 구성이 다시 열리고, 공유 시점의 디자인을 읽기 전용으로 확인             |
| 55–75초       | 편집 탭으로 돌아가 **사이즈 · 주문 검토** → 사이즈 270 → **이 디자인 주문하기**. 준비된 가상 배송지와 총액 확인 → **모의 결제하기** | 실제 개인정보·청구 없이 주문 생성, 주문 상세에서 디자인·사이즈·금액 확인     |
| 선택: 75–90초 | 주문 상세에서 출고 준비 → 배송 중 → 배송 완료 진행                                                                                  | 사용자가 직접 진행하는 배송 시뮬레이션. 취소·반품·모의 환불도 별도 체험 가능 |

첫 화면에서 “실제 판매·결제·배송이 없는 포트폴리오입니다”라고 짧게 안내해. 3D 실패 시 사진만 표시된 상태를 편집 성공으로 설명하지 말고, 다시 시도하거나 해당 시연을 보류해. PNG 내보내기·수정 충돌 복구는 시간이 남는 별도 시연으로 보여줘.

## 게스트와 계정

- 로그인 없이 디자인·찜·장바구니·모의 주문을 사용할 수 있어. 게스트 체험은 브라우저에 저장된 쿠키로 구분하며, 쿠키를 지우거나 다른 브라우저를 사용하면 같은 체험으로 이어지지 않을 수 있어.
- 소셜 로그인하면 게스트 데이터와 기존 계정 데이터를 이어서 보관하는 흐름을 구현했어. 계정은 제공자 ID로 식별하고, 서로 다른 소셜 서비스의 계정을 이메일만으로 합치지 않아.
- Google·Kakao·Naver 중 현재 환경에 설정된 제공자만 사용할 수 있어. 로그인 취소·실패 안내와 게스트 대안을 제공하지만, 실제 제공자별 로그인·동의·기존 계정 이관 완주는 별도 수동 검증 대상이야. 기본 75초 시연에 인증을 포함하지 않아.
- 공유 링크는 생성 후 7일간 유효해. 게스트는 7일 미접속 후 기존 체험 접근이 종료돼. 조회 만료와 데이터의 물리 삭제 시점은 다르며, 정리 도구 구현이 운영 자동 정리 활성화를 뜻하지 않아.
- 결제·배송·재고·환불은 모두 체험용이야. 가상 주소를 사용하고 실제 주소·연락처·카드 정보를 입력하지 않아. 장바구니와 주문에 표시된 가격은 실제 판매가나 제조 견적이 아니야.

## 남은 검증과 경계

- 실제 Google·Kakao·Naver의 성공·취소·실패·기존 계정 이관은 계정 소유자가 참여하는 검증이 필요해. 제공자 설정과 자동 테스트만으로 완료를 주장하지 마.
- 데스크톱 1440/1280과 모바일 390의 브라우저 검증은 iOS Safari·Android 실기기, 보조 기술, 저사양 GPU·느린 네트워크의 결과를 대신하지 않아. 3D 조형의 최종 승인도 따로 기록해.
- PostgreSQL 경쟁 조건·백업 복원은 전용 검증 DB의 결과로 확인해야 해. 로컬 SQLite 통과를 운영 PostgreSQL 검증으로 설명하지 마.
- 실제 결제·배송·상품 제조, 문의·후기, 별도 관리자, 임의 부품 형태 교체는 제공하지 않아. 로컬 구현·테스트·공개 배포는 서로 다른 완료 상태야.
